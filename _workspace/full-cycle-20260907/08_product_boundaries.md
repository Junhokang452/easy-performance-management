# 제품 소유권 및 인계 경계

2026-09-07 공유 조정 작업의 사용자 추가 지시 반영.

- easy-performance-management: 일반 인사평가, 성과/역량 평가, 개인·부서 목표와 OKR, 목표합의, 중간점검, 자기평가, 1~3차 평가, 보정, 최종피드백/이의, 마감/개인공개, 일반 평가통계, 성과과제 및 면담 증빙.
- easy-mra: 별도 작업 'RootHR 참고 다면진단 시스템 보완'이 캠페인, 다면진단 응답, 익명 집계/리포트 원장을 소유한다. performance에는 새 다면진단 원장을 중복 구현하지 않는다.
- easy-learning-management: 교육·학습·IDP 소유. 이 평가 작업에서 학습 운영 원장을 중복 생성하지 않는다.

보존 및 인계:
- RootHR 성과·역량 운영 개요에 나타난 다면평가 언급은 분석 원문 추적에 남긴다. 기존 산출물을 삭제하거나 되돌리지 않는다.
- 초기 ProgramTypes/DTO의 COMBINED/MULTI_RATER enum 값은 호환 흔적으로 보존하되 현재 프로그램 생성 서비스는 PERFORMANCE/COMPETENCY만 허용한다. UI 생성 선택지는 실제 지원 유형만 제공한다.
- 기존 easy-mra/talent/LMS S2S 계약과 read-model 경계는 유지한다. 해당 제품의 캠페인·익명 응답 데이터를 성과평가 DB의 새 원장으로 복제하지 않는다.
- 결과/증빙 교환은 각 제품의 확정 결과 계약을 후속 조율하며, 공유 UI/인증/테넌트/파일교환 라이브러리만 공통화한다.
