- 공통 MasterDetailWorkspace: 타입 빌드, Storybook 빌드 성공; Chromium 1440/390px 배치/수평오버플로/페이지오류 검증 통과.

- 공유 FE 의존성 호환 patch: npm audit 0 (shared-audit-fix.log). 제품 FE는 별도 검증 필요.
