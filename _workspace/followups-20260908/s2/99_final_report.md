# S2 KPI 연계 완료 보고

2026-09-08. **S2 구현·로컬 검증 완료.** S1 완료 상태를 유지한다. S3 책임자 독려 및 S4 맞춤 PDF는 아직 구현하지 않았다.

## 결과

합의된 평가 목표 하나에 KPI 배정 하나를 명시적으로 연결한다. 운영자가 목표·주기·실적 기준일·KPI를 선택한 뒤 서버 미리보기와 사유 확인을 거쳐 근거를 저장한다. 목표값/가중치는 저장 시점의 현재 정의이고, 실적은 정정 이력의 유효한 최종 항목을 기준일에 맞춰 선택한다.

근거는 목표별 불변 버전으로 보존한다. 같은 요청의 동시 실행·재시도는 같은 이력을 반환하고, 갱신은 해당 목표의 이전 근거만 대체한다. 목표 A 갱신이 목표 B에 영향을 주지 않는다. 이전 요청을 재전송해 과거 근거를 다시 활성화할 수 없다.

기능은 **참고 근거 전용**이다. 기존 목표·가중치·목표값·평가 제출·최종 점수/등급은 변경하지 않는다. 직원과 배정된 평가자는 저장 근거를 읽기 전용으로 확인한다. 평가자 제출 완료 또는 결과 계산 이후 새로운 근거 갱신은 차단한다. 자기평가 완료만으로는 차단하지 않는다.
