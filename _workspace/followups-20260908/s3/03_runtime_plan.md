# S3 실제 검증 계획 (아직 결과 아님)

Root 소유: scripts/verify-responsible-reminders-local.py 및 브라우저 verifier/증거. 계약 확정 전이므로 아래는 검증 요구사항이며 endpoint/DTO는 01_backend_contract.md로 확정한다.

## 실제 HTTP + 전용 PostgreSQL

1. 기존 dev 직원 4~5명을 사용하는 합성 프로그램·참여자·평가자·목표를 생성한다. 운영 데이터는 복사하지 않는다.
2. 목표 초안/반려는 직원, 합의 요청은 지정 합의자, 자기평가는 직원, 현재 차수 평가자는 실제 배정자라는 구분을 검증한다.
3. 중간 검토·조정·피드백 작성/확인/이의 해결의 실제 담당자 구분을 계약대로 검증한다. 인위적 HR 단계 override를 쓸 경우 fixture 설정이라고 표시한다.
4. 미배정/비활성 직원/제외·완료/아직 시작하지 않은 단계/운영자 전용 작업은 잘못된 대체 수신자를 만들지 않는다.
5. 미리보기 전후 알림·업무 상태 무변경, 사유 없는 요청 거부, 비운영자 API403, 다른 프로그램/실제 다른 tenant 객체 차단.
6. 같은 preview 동시 적용/재시도는 한 번의 내부 알림 등록. 새 preview로 같은 날 재시도해도 duplicate 상태. 문구/마감일 편집이 dedupe를 우회하지 않는다.
7. preview 이후 완료/담당자 변경은 stale 거부하며 업무 내용이나 점수가 바뀌지 않는다.
8. UTC 날짜 경계/다음 날 재독려는 주입 Clock 단위 테스트로 검증하며 시스템 시계를 바꾸지 않는다.
9. 해당 직원 알림함에만 IN_APP 노출; 이메일 READY/SENDING 생성 없음; 다른 직원의 읽음 표시 요청 거부.
10. 알림 본문은 일반 텍스트, 평가 점수/의견 무단 노출 없음. template 치환 후 길이가 DB 한도를 초과하면 500 대신 명시 검증 실패.

## FE/브라우저

5locale × desktop/mobile, 미리보기 수신자/업무/blocked/duplicate 라벨, UTC일자 안내, 사유필수 확인·취소무변경, 실제 등록 결과와 수신자알림함, stale 재미리보기, HR-only 표면을 확인한다. root가 계약 fixture 준비 후 실행하며 Terra는 type/build/i18n/규칙 게이트를 담당한다.

## 마무리

S1/S2 핵심 회귀, BE 전체 테스트, 실제 OpenAPI 재생성+tsc, 소스와 검증 사본 SHA 정합. 최종 증거 저장 후 전용 API8089/PG55489 종료 및 기존 PG5432/5433 보존 확인. 외부 SMTP/DB·push·배포·커밋 없음.
